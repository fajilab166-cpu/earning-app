# 💰 Earning App

Simple rewarded ads earning app using AdMob.

---

## 🚀 Features

* 📺 Watch Ads & Earn
* 💵 Real-time Balance System
* ⚡ Simple & Clean UI

---

## 🔥 Upcoming Features

* 👥 User Account System
* 🎁 Referral System
* 📅 Daily Tasks
* 💸 Withdraw System (bKash / PayPal)
* 🏆 Leaderboard

---

## 🛠️ Technologies

* Android (Java/Kotlin)
* Google AdMob

---

## 📲 How It Works

1. Open the app
2. Click "Watch Ads"
3. Watch full ad
4. Earn reward

This app is for learning/demo purposes. Earnings depend on ads.
